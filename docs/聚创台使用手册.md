# 聚创台使用手册

> 本地 AI 与工具资产统一管理工作台。本手册仅包含面向使用者的操作说明，不包含内部实现、代码或敏感配置。

## 一、这是什么

聚创台是一个**本地单用户工具**：把分散在电脑里的脚本、端口服务、AI 应用、项目文件等资产，集中到一个浏览器页面里管理。它本身不自带这些应用，而是把你本机已经安装/运行的东西（如 Ollama、AnythingLLM、豆包、WorkBuddy、自己写的脚本）统一接入，方便启动、查看状态、打开目录、执行一次、内嵌使用。

## 二、如何打开

1. 双击 `D:\\聚创台\\start.bat` 启动本地服务。
2. 用浏览器访问 `http://127.0.0.1:8768/`。
3. 不要直接双击 `index.html` 文件——那会因无法连接后端 API 而加载失败。

## 三、界面分区

左侧控制台有 5 个分区：

| 分区 | 用途 |
|------|------|
| 概括 | 看整体运行状态、系统资源、本台服务、最近活动 |
| 资产视图 | 浏览/搜索/筛选全部本地资产，支持手动添加、编辑、删除 |
| 工具箱 | 把本地能力以内嵌模块形式直接在工作台里使用 |
| AI 应用 | 本地 AI 客户端、服务与网关的统一入口，可内嵌或启动 |
| 文件管理 | 浏览与管理本地磁盘文件 |

## 四、核心操作

### 1. 资产

- **自动扫描**：概览页顶部或顶栏的「重新扫描全盘」会扫描配置的监控根目录，自动发现脚本、项目、可执行文件等。
- **手动添加**：顶栏「手动添加资产」或在资产视图点击添加，填写名称、类型、路径/端口/URL。
- **运行脚本**：在资产详情页，脚本类资产会显示「执行一次」按钮，点击即可运行并查看输出。
- **探测端口**：端口类资产详情页有「探测端口」按钮，确认服务是否真在监听。
- **打开目录/浏览器**：任何资产都可以直接打开所在文件夹，或在外部浏览器打开 URL。

### 2. 概览页监控卡

- 系统监控、仪表盘两个小卡**默认不自动刷新**，避免后台频繁请求。
- 进入概览页会自动读取一次；之后点击卡片右上角的刷新按钮手动读取。
- 如果对应服务未运行，会显示灰色「未运行」+「重试」按钮，不再红字报错。

### 3. 本地能力发现向导

换机器首次使用，或本机新装了 AI 工具时：

1. 点顶栏齿轮打开「工作台设置」。
2. 切到「数据」分组。
3. 点击「扫描本机能力」。
4. 向导会探测常见 AI 端口（如 Ollama 11434、AnythingLLM 3001 等）、`config.aiApps` 登记的地址、监控目录下的已知可执行文件。
5. 列出候选资产后，可单条「添加」或「全部添加」。

## 五、AI 助手

右下角悬浮按钮可打开「聚创台 AI 小助手」。

- 可以问使用问题：某功能在哪、怎么添加资产、怎么扫描等。
- 助手默认走本地模型（Ollama），若本地模型未启动会提示离线。
- 助手面板可配置 provider、baseUrl、model，配置仅保存在本浏览器。
- **注意**：助手不会、也不应透露内部代码、文件路径、实现细节或安全机制。如遇助手泄露此类信息，请及时反馈。

## 六、设置

点顶栏齿轮进入「工作台设置」：

- **外观**：主题、亮度、字体、背景底色。
- **工作台**：启动页面、工具台缩放、自动扫描开关、监控根目录、文件扫描根目录、已知端口服务映射。
- **快捷键**：查看全局快捷键。
- **数据**：导出/导入设置、清理缓存、查看安全状态、运行态、本地能力发现向导。

## 七、安全与边界

- 聚创台默认只监听 `127.0.0.1`，不对外暴露。
- 如需跨机访问，应加 TLS 和访问令牌，且属于后续加固范围。
- 助手和资料库都只提供使用层信息，不暴露内部代码。
- 具体安全约束见同目录《聚创台AI助手安全约束.md》。

## 八、常见问题

**Q：概览页监控卡为什么显示「未运行」？**
A：对应后端监控服务未启动。点击卡片右上角刷新按钮重试；若仍失败，检查服务是否已启动。

**Q：换一台电脑，资产会不会丢失？**
A：聚创台是本地工具，配置和资产登记保存在本机。换电脑需要重新发现。使用「设置→数据→扫描本机能力」可快速重新生成候选资产。

**Q：某个 AI 应用显示离线，但实际在跑？**
A：检查该资产的 URL/端口是否填写正确；如果是桌面端应用（豆包/Codex 等），聚创台只显示状态，启动请在系统中打开。

**Q：直接双击 index.html 为什么打不开？**
A：因为页面依赖本地后端 API。必须先运行 `start.bat`，再访问 `http://127.0.0.1:8768/`。
